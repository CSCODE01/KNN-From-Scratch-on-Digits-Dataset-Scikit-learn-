# KNN From Scratch on Digits Dataset

## Project Overview
This project implements the K-Nearest Neighbors (KNN) algorithm from scratch using Python and applies it to the Scikit-learn Digits dataset for a classification task.

## Workflow
- Load the digits dataset using Scikit-learn
- Data cleaning (checking missing, duplicate, and outlier values)
- Feature scaling using StandardScaler
- Label encoding
- Train-test split (80% training, 20% testing)
- Building a custom KNN classifier (Euclidean and Manhattan distance)
- Model evaluation using:
  - Accuracy Score
  - Classification Report
  - Confusion Matrix

## Objective
The goal of this project is to understand how KNN works internally by implementing it manually instead of using the built-in Scikit-learn KNN model.

## Technologies Used
